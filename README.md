# SPDX data branch

Generated by `.github/workflows/spdx-bundle.yml` on `main`. Do not edit by
hand, and do not force-push.

`spdx/format-1/` holds one bundle per SPDX License List release
(`v<version>.json.gz`) and `latest.json`, which names the newest one.
`licenseid update` and the package build fetch them from
`raw.githubusercontent.com`.
